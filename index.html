如何安裝 PWA 應用程式

本應用程式支援 PWA (Progressive Web App)，您可以將其安裝至您的桌面或手機主畫面，安裝後即可完全離線運作！

Windows 系統 (Chrome / Edge)

1. 使用 Chrome 或 Edge 瀏覽器打開此網頁。
2. 點擊網址列右側的「安裝」圖示（或點擊右上角選單 $\rightarrow$「安裝深層海水營養鹽濃度換算器」）。
3. 確認安裝後，即可建立桌面捷徑並獨立視窗開啟。

macOS 系統 (Chrome / Safari)

Chrome：點擊網址列右側安裝按鈕。
Safari (macOS Sonoma 以上)：點擊頂部選單「檔案」$\rightarrow$「加入側邊欄或Dock」。

Android 系統 (Chrome)

1. 使用 Chrome 打開網頁。
2. 點擊右上角選單（三個點） $\rightarrow$「加到主畫面」或「安裝應用程式」。
3. 依照提示確認即可安裝至手機桌面上。

iOS 系統 (iPhone / iPad - Safari)

1. 必須使用 Safari 瀏覽器打開此網頁。
2. 點擊下方工具列的「分享」按鈕（正方形帶向上箭頭）。
3. 在選單中向下滑動並點選「加入主畫面」。
4. 點擊右上角「新增」，App 圖示即會出現在 iPhone 桌面上。

海洋學參考標準值與換算常數

1. 原子量與分子量常數

  • 氮 (N)： 14.0067 g/mol | NO3-： 62.0049 g/mol
  • 磷 (P)： 30.9738 g/mol | PO43-： 94.9714 g/mol
  • 矽 (Si)： 28.085 g/mol | SiO2： 60.08 g/mol | SiO44-： 92.08 g/mol

2. 海水密度與克分子換算

在深層海水分析中，1 μM 代表 1 μmol/L。轉換為重量莫耳濃度 (μmol/kg) 需除以海水密度 ρ ($\approx 1.025\text{ g/cm}^3$)：
μmol/kg = μM / ρ

3. 深層海水營養鹽背景值參考 (約略範圍)

  • 硝酸鹽 (NO3-)： 20 - 40 μM (深層水常顯富集)
  • 正磷酸鹽 (PO43-)： 1.5 - 3 μM
  • 矽酸鹽 (SiO2 / Si)： 30 - 60 μM
